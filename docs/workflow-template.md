# Mini CRM Rescue Workflow Template

Use this template to fork the demo into a real internal tool while keeping the public repo fictional and credential-free.

## Audience

Small sales teams cleaning a messy spreadsheet or lightweight crm.

## Operating Promise

This demo shows how to deduplicate leads, expose owner gaps, prioritize follow-up, and package a cleaner pipeline for handoff.

## Demo Metrics To Adapt

- Leads with owner gaps
- Follow-ups ready
- Duplicate risk
- Export package coverage

## Fork Checklist

- Replace sample deals with your fictionalized CRM rows first.
- Score priority by revenue/urgency and friction by missing data.
- Use the inspector to document next step and owner.
- Export a normalized CSV for the next sales-ops pass.

## Public-Safe Data Rules

- Use fictional people, accounts, tickets, deals, notes, and companies.
- Do not add secrets, API keys, private URLs, customer exports, or production screenshots.
- Keep the app static unless you intentionally add a backend in a private fork.
